BALAN E-Commerce Website
A full-stack e-commerce web application developed using React.js, Tailwind CSS, Node.js, Express.js, MongoDB Atlas, and Mongoose.
Features
User
- User registration and login
- Browse and search products
- Product details
- Add to cart
- Checkout and delivery details
- Cash on Delivery
- Order confirmation
- View my orders
- Logout
Admin
- Admin login
- Dashboard
- Add, edit, and delete products
- View customers
- View orders
- Update order status
- Logout
Technologies
- React.js
- Tailwind CSS
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- GitHub
- Render
